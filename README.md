# mohiemen.com

Personal site for M A Mohiemen Tanim — industrial engineer, innovation consultant, and founder of Intelactory.

Static site, no build step. Pages: `index.html`, `projects.html`, `blog.html`, `contact.html`.

## Deploy

Serve this directory as-is with Nginx or Apache (e.g. copy to `/var/www/mohiemen`). No Node/PHP/Docker runtime required.
